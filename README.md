ply_pointcloud_viewer.m 作用：生成一个选择界面，然后进行点云的可视化，可视化的时候，可以保存图片文件，还会显示点云的相关信息

display_ply_pointcloud.m 作用：运行程序以后，可以选择对应的点云文件，然后进行点云的可视化

fringe_gray_analysis.m 作用：比较高动态的条纹图像和经过网络模型处理过的正常的灰度模型的正弦变化的情况，可以自己选择roi区域，自己选择对应的行和列，然后可视化选择的行或列上的条纹的正弦变化情况，还可以将高动态的图像和基准的图像进行比较，直接观察比较的结果。

integrated_absolute_phase_tool.m 作用：从采集到的条纹图像中生成绝对相位，在有掩码（可以自由选择掩码还有行和列），然后可以可视化并且保存掩码部分（有掩码存在的情况下）的相位结果，还有掩码部分的绝对相位的二维变化的图像。

npy_to_mat_converter.m 作用：将得到的npy文件转为MATLAB可以识别的.mat，然后进行保存

phase_2d_visualization_compare2d.m 作用：可以同时加载多个绝对相位（是经过解包裹后的绝对相位）结果，生成对应的相位变化的 3D 相位表面图，并在同一张 2D 曲线图中对指定行的相位变化进行对比分析。即也可以像上面那样，对与指定的行或者列进行绝对相位上的相位的走势（相位的变化的情况）（二维图像上的）

phase_Compare.m 作用：对两幅绝对相位结果进行逐点误差分析与 3D 可视化，这里可视化的对象必须应该是解包裹后的绝对相位（也可以是掩码过后的绝对相位），然后3D可视化的也是绝对相位在三维空间中的可视化。同时比对解包裹算法或参数配置的重建精度。即在相位程度上对比得到基准相位和待比较相位的误差情况（大于误差阈值的相位点会被标红）。

phase_visualization.m 作用：对单幅绝对相位结果（或者包裹相位结果）进行 3D 表面可视化，这里不仅可以可视化绝对相位，还可以可视化包裹相位，并抽取指定行的 2D 相位变化曲线做定量分析。这里选择指定行就没有那么智能了，只有几个有限的选择去选择，不过也可以显示绝对相位的相位的走向。只要是相位就都可以使用这个文件进行可视化显示。

pointcloud_compare.m 作用：可以选择两个PLY 点云进行几何误差对比，统计最近邻距离误差。在设置好点云见的误差阈值以后，对于低于阈值的点保留原始 RGB 颜色，对于高于阈值的点用柔和暖色渐变（浅黄→橙→深红）表示误差大小，并显示颜色条。最后将保留误差信息的结果可视化显示出来，并且保存下来。

three_frequency_phase_visualization.m 作用：可以读取3个频率的N步相移条纹图像，然后计算三个频率的包裹相位并保存（后续可以phase_visualization.m进行包裹相位的可视化），然后利用多频外差/塔形展开逻辑生成绝对相位并保存，然后读取掩码文件（.mat/.npy 或图像格式），提取掩码区域内的绝对相位，最后保存绝对相位与掩码相位为 .mat 格式。

mat_visualization.m 作用：可以读取.mat文件中信息，然后选择对应的信息进行可视化，就是可视化.mat文件的工具

wrapped_phase_2d_visualization_compare2d.m 作用：可以同时加载多个包裹相位结果，生成其 3D 包裹相位表面图，并在同一张 2D 曲线图中比较指定行的包裹相位变化及相位跳跃次数。主要针对的是包裹相位，可以可视化包裹相位，并且将待比较的包裹相位和基准包裹相位进行比较。
