## MATLAB 工具箱概览

本项目包含一组用于“条纹投影相位处理”和“PLY 点云误差分析/可视化”的 MATLAB 脚本。下面每个脚本的功能说明均尽量贴合其交互方式、输入输出与保存结果，便于你直接选用。

### 点云可视化与误差分析

`ply_pointcloud_viewer.m`：UI 方式的 PLY 点云查看器。可通过按钮选择并打开 `.ply` 文件，显示点云基础信息（点数、XYZ 范围、是否含颜色等），支持 `Downsample` 网格下采样、`Reset View` 重置视角，并可 `Save Screenshot` 保存当前视图截图。

`display_ply_pointcloud.m`：命令脚本形式的 PLY 点云交互查看器。运行后弹出对话框选择 `.ply`，在图窗内显示点云；通过键盘快捷键完成视角控制（`R` 重置）、数据光标模式切换（`D` 点击查看点的坐标）、轴视图切换（`X/Y/Z`）、点大小调整（`+/-`）、保存当前视图（`S`）与退出（`Q`）。

`pointcloud_compare.m`：两帧 PLY 点云的几何误差对比（最近邻欧氏距离）。脚本交互式选择基准点云与待比较点云，设置 `THRESHOLD` 后：
阈值以下点保留原始 RGB（如存在）；阈值以上点用柔和暖色渐变（浅黄→橙→深红）映射误差大小并显示颜色条。
同时生成误差直方图（含阈值附近局部放大）与混合着色点云可视化，并输出/保存结果点云。

### 条纹图像灰度剖面分析

`fringe_gray_analysis.m`：条纹投影图像（相机采集到的条纹图像）灰度变化分析工具。支持单图模式与双图对比模式（用于比较高动态即高反光图像和漫反射图像的相同位置的灰度变化），流程包括：
读取图像（彩色自动转灰度）；
交互式 ROI 框选，并选择提取方向（行 `Row` 或列 `Col`）；
在 ROI 内点击选定具体行/列，提取灰度剖面并计算统计量（可以看到正弦曲线的变化情况与整体的走势）；
在生成的图窗中同时显示关键结果并立即保存（窗口保持开启便于交互）。

### 相位生成与相位可视化

`three_frequency_phase_visualization.m`：三频相位处理与可视化。读取 3 个频率段的 `N_STEP` 步相移条纹图像，计算各频率包裹相位并保存（后续可以可视化）；利用多频外差/塔形展开逻辑生成绝对相位；再结合掩码（`.mat/.npy` 或图像格式）提取掩码区域内的相位，并保存为 `.mat`；同时生成多个可视化窗口（如 3D 表面图、2D 伪彩色图、相位曲线等），窗口保持开启以便点击查值。

`integrated_absolute_phase_tool.m`：绝对相位“整合版”一体化流程工具。强调 ROI 掩码选择与行/列分析联动：
先基于背景图选择 ROI（交互式或手动），生成掩码；
根据掩码与 ROI 选择行/列，确定全局分析索引；
计算绝对相位并保存（变量名为 `phase_data`，与后续可视化脚本兼容）；
输出掩码文件 `mask/`、相位数据 `phase_data/` 与 `visualization/` 目录中的曲线/伪彩色/可选 3D 表面图等结果。

`phase_visualization.m`：单幅相位通用可视化（可用于绝对相位或包裹相位，只要输入是相位二维矩阵）。脚本会进行 3D 表面可视化，并选择指定行提取 2D 相位变化曲线（`position` 自动选择或可手动指定索引），同时打印相位范围与曲线统计量，便于定量对比。

`phase_2d_visualization_compare2d.m`：多幅绝对相位的对比可视化（2D 曲线 + 多个 3D 表面图）。可加载多个绝对相位 `.mat`，逐一生成 3D 表面图；再在同一张 2D 曲线图中对指定行的相位走势进行对比，并对中间区间进行线性拟合，图例中给出斜率等信息。

`wrapped_phase_2d_visualization_compare2d.m`：多幅包裹相位的对比可视化。生成多份包裹相位的 3D 表面图；并在同一张 2D 图中比较指定行的包裹相位曲线，同时基于 `pi` 阈值统计相位跳跃次数（在图例中展示），用于包裹相位质量评估与算法对比。

`phase_Compare.m`：两幅绝对相位的逐点误差分析与 3D 误差可视化。脚本会计算 `delta_phi = phase_compare - phase_base`，统计数据质量（NaN/Inf）、计算 RMS/Success Rate/误差点数量等指标，并在 3D 图中用“误差 spikes”（`stem3`）标注误差较大的位置，便于快速定位重建误差分布。

### .mat / .npy 数据查看与转换

`mat_visualization.m`：MAT 文件通用查看器。选择 `.mat` 后会列出变量并让你选择目标变量；根据变量维度自动显示：1D 折线、2D `imagesc` + colorbar、3D 中间切片；也会对结构体中“第一个可显示的数值字段”进行自动可视化尝试。

`npy_to_mat_converter.m`：NumPy `.npy` 到 MATLAB `.mat` 转换器。脚本通过 Python 读取 `.npy`（检查 Python/numpy 环境），并对维度顺序进行必要转置/permute 以匹配 MATLAB 列主序常见需求；将数据保存为指定变量名（默认 `phase_data`）的 `.mat`，并可在末尾对保存结果进行一致性验证（逐元素 `isequal`）。
